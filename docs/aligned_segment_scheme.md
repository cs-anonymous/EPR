# ABCX + MIDI-TSV 切割方案

目标是构造一组**无重叠**的配对片段，让 `ABCX` 与 `MIDI-TSV` 使用同一套小节切点。

## 规则

- 基本单位是**小节边界**，不在小节内部切。
- 常用长度是 **8–16 小节**。
- 目标时长是 **20–40 秒**。
- 切点优先落在句末、终止式、重复号、长休止之后。
- 不做 bridge overlap，避免样本重复和对齐复杂度上升。

## 策略

1. 先把 ABCX 的正文展开成小节序列，每个小节都有全局小节号。
2. 统计相邻小节组成的候选片段长度，并用固定速度估算时长。
3. 从左到右累计小节，直到满足最小长度，再在允许窗口内挑选最像句末的位置。
4. 用同一组小节边界去裁 ABCX 和 MIDI-TSV，输出为一对一片段。

## 输出

- `segments.json`：记录每个片段的小节范围、对应 row 范围、起止 tick、起止秒数。
- `*.segNNNN.abcx`：对应的 ABCX 片段。
- `*.segNNNN.mid.tsv`：对应的 MIDI-TSV 片段。

## 约束

- 该方案适用于固定速度、固定拍号或拍号变化很少的曲子。
- 如果存在复杂的中途变拍或变速，后续可以再扩展为更细的规则。
