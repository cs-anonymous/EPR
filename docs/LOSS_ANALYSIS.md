```

扩展词表：248,601 tokens（新增 524 个MIDI tokens）
```

**影响：**

**类比：**
- 之前：从248K个词中选一个（容易）
- 现在：从248.6K个词中选一个（稍难）
- 而且新增的524个词模型完全不认识

- 任务难度不同
- **Loss不可直接比较**

### 3. **LoRA训练 vs 全参数训练**

## 🔬 深入理解

### 为什么扩展词表后loss会高？

**数学解释：**
```
Cross-Entropy Loss = -log(P(correct_token))

原始词表：P(correct_token) = 1/248077 → loss ≈ log(248077) ≈ 12.4
扩展词表：P(correct_token) = 1/248601 → loss ≈ log(248601) ≈ 12.4

但实际上：
- 原始tokens：模型已经训练好，P(correct) 很高 → loss低
- 新增tokens：随机初始化，P(correct) 很低 → loss高
```

**你的数据中如果包含很多新增的MIDI tokens，loss自然会高！**
